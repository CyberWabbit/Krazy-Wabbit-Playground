# Publication checklist

- [x] Add the approved MIT license to the project and static site directory.
- [x] Review the final files and rerun the build and automated tests.
- [ ] Obtain owner approval to publish.
- [ ] Create the public repository and follow the [Pages setup](GITHUB_PAGES.md).
- [ ] Verify the live HTTPS URL, all three instruments, and MIDI permission with the Roland S-1 or another known device.
- [ ] Tag the approved commit and attach the matching ZIP. Keep the private approved-version backup outside the repository.
